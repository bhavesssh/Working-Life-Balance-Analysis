🧠 Working Life Balance Dashboard
📌 Project Overview

The Working Life Balance Dashboard is an interactive data analytics project that examines how daily lifestyle habits—work, sleep, exercise, and rest—influence lifespan (age at death). The project helps users understand the importance of maintaining a balanced daily routine for long-term health and longevity.

📊 Dataset Summary

Records: 10,000 individuals

Type: Synthetic dataset with realistic lifestyle patterns

Key Attributes:

Age at Death

Occupation Type

Average Work Hours per Day

Average Sleep Hours per Day

Average Exercise Hours per Day

Average Rest Hours per Day

Gender

The dataset is designed so that daily activities sum to approximately 24 hours, including some outliers to support deeper analysis.

🛠️ Tools & Technologies

Python – Data cleaning and preprocessing

SQL – Data analysis and aggregations

Power BI – Interactive dashboard and visualizations

GitHub – Version control and project sharing

📈 Dashboard Features

KPI cards showing key lifestyle and longevity metrics

Scatter plot analyzing Work Hours vs Lifespan

Bar charts for Occupation-wise and Gender-wise lifespan comparison

Line and column charts for Sleep and Exercise impact

Stacked column chart showing 24-hour daily time allocation

Interactive filters (slicers) for occupation, gender, and age range

🔍 Key Insights

Moderate work hours are associated with higher lifespan

Balanced sleep (7–8 hours) positively impacts longevity

Regular, moderate exercise improves health outcomes

Occupation plays a significant role in daily time allocation

Overall lifestyle balance is more important than any single factor

🎯 Use Cases

Work–life balance analysis

Health and lifestyle research

Data analytics portfolio project

Client or stakeholder presentations

▶️ How to Use

Open the Power BI .pbix file

Use slicers to filter by occupation, gender, or age

Explore interactive charts to identify lifestyle patterns

📌 Conclusion

This project demonstrates how data analytics and visualization can be used to gain meaningful insights into lifestyle choices and their long-term impact on health and longevity.
